# 路线图

- [x] 统一日线数据契约与校验。
- [x] 基础因子和截面目标权重。
- [x] 下一交易日执行、T+1、手数、涨跌停和费用。

## P0.5：方向发现

- [ ] 调用 `a-stock-data` 获取行业排名、板块资金流、热点和涨停题材。
- [ ] 调用 `plate-rotation-skill` 获取短线板块排名、持续性和龙头数据。
- [ ] 将外部结果标准化为市场状态、行业方向、概念方向和证据明细四张表。
- [ ] 复用 `stock-screener` 的多周期相对强度/RRG方法，形成中期方向信号。
- [ ] 交叉验证短线与中期方向；单一来源异常时不得生成确定性结论。
- [ ] 方向结果先做 walk-forward 和样本外验证，再进入日报解释层。
